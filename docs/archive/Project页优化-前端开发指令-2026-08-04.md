## 2. 阶段 A：树行重构（`src/app/(dashboard)/projects/page.tsx`）

### A1 层级视觉（对照副本 v3.1）

| 层级 | 视觉 | 实现 |
|------|------|------|
| L0 项目根 | 浅底分组头（`--group-bg #f4f6fb`）+ 左侧 3px 彩色竖条 + 13.5px 加粗 + 实心圆点 | `class="trow lvl0"` + `style="--pcolor/--pbg"`（来自后端派生色） |
| L1 阶段/积累 | 白底 + 空心品牌圆点（积累=金边）+ medium | `class="trow lvl1"` |
| L2 任务 | 白底 + 灰色小实心点 + regular | `class="trow lvl2"` |

### A2 树状连接线

- 每行缩进区（`--ind` 26/46/66px 递增）+ 竖线 + 横折线（CSS 伪元素，副本 `.indent::before/::after`）
- 动态维护：`no-prev`（行首无竖线）、`last-group`（组尾竖线收半）——拖拽/新建后重算

### A3 树行瘦身（保留 PM 意见）

- 行元素：展开箭头 + 层级圆点 + 名称 +（徽章/主题角标）+ ★ + 完成度 + hover 操作钮
- **打卡格子和"连续天数"文字移出树行**——积累型只留金色打卡点（金=今日已打卡/灰=未），打卡统一在习惯区
- 完成度：行尾 `3/6`、`2/5`、`12天`（数据见 §5 后端契约，前端消费即可）

### A4 模式 A/B 删除

- 删掉「单任务聚焦/同级任务」双模式（`mode/bOpen` state 清理）
- 点节点统一打开档案面板（阶段 D）

## 3. 阶段 B：交互

| # | 交互 | 说明（照副本 JS） |
|---|------|------------------|
| B1 | 拖拽归属 | HTML5 DnD：拖到行上=成为子级（虚线高亮 `drag-over-child`）；拖到上/下 1/3 区=换序（金线 `drag-over-before/after`）；drop 后更新层级 + 重绘连接线 + toast |
| B2 | 新建 | 右上「＋新建项目」/ 行尾「＋」→ inline input（Enter 创建 / Esc 取消）→ 自动挂父级、自动层级、自动缩进 |
| B3 | ★ 清单开关 | 点 ★：`is-list` 类切换 → 「执行清单」徽章显隐；同步写后端（`tasks/[id]` 的 star/listFlag 字段，见后端指令 §3） |
| B4 | 展开收起 | ▾/▸ 切换子树显隐（真实实现需维护折叠 state 集合） |
| B5 | hover 操作钮 | 行尾 ＋ / ↑ / ↓（仅 hover 显示） |

## 5. 阶段 D：档案面板 + 派生色

- **档案面板**：点节点滑出（右侧 400px），复用/对齐全站 TaskDetailPopover 风格——归属链 + 元信息 + memo 黄执行清单 + 执行类型开关 + AI 建议
- **派生色消费**：分组头 `--pcolor/--pbg` 直接取后端返回的 themeColor 字段（见后端指令 §3），**前端不做颜色计算**
