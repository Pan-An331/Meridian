## B · P1-4 Inbox 输入框可取消 ✅

**文件**：`src/app/(dashboard)/inbox/page.tsx`（InputCanvas）

- **根因**：Escape 只 `setValue("")` 清空值，输入框（textarea）仍聚焦展开，无法"关闭"（改进清单核实）
- **改动**：
  - 新增 `closeInput()` = 清空 + 失焦（`blur()`）+ 高度复位（`style.height="auto"`）
  - **Escape → `closeInput()`**（关闭输入框，不再只是清空）
  - **「✕ 取消」按钮**：footer 新增（有内容时显示，点击同 `closeInput()`）
  - **blur → 关闭**：失焦时内容为空则收起高度（视觉关闭）；有内容保留防误丢（避免点「AI 整理」按钮时 blur 清空导致发送失败）
  - footer 提示文案更新：「Esc 清空」→「Esc 关闭输入」
- **✅ 验收标准达成**：任意时刻能取消新建（Esc / ✕ / 失焦），不强制完成
