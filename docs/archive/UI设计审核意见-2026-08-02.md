# Task OS · UI 设计审核意见书（第三轮 · 纯设计视角）

> 审核人：UI Designer · 2026-08-02 03:56-04:05
> 方法：真实渲染审计（DOM computed style + 像素级颜色分析）—— 不读代码，只看画面
> 原则：只给意见，不改代码

---

## 〇、总体判断

页面已经"能用、干净、字够大"，但距离"好看、有质感"还差一层。核心问题不是单个元素丑，而是**三个系统性问题**：① 整页 73-80% 是同一片浅灰白，层次靠"几乎看不见的线"；② 圆角/字号语言不统一，页面之间割裂；③ 品牌靛蓝与 AI 紫视觉上分不清，色彩叙事混乱。

---

## 一、P0 · 必须修（设计系统硬伤）

### 1. 圆角语言不统一（跨页面割裂感来源）
实测各页面卡片圆角：
| 页面 | 圆角分布 |
|---|---|
| settings | **20px×8** + 12px×4 |
| today | 16px×3 + 12px×2 + **8px×7** |
| review | 16px×3 + 12px×1 |
| plan | 16px×3 + 12px×1 + 8px×2 |

同一个产品里，settings 的大卡 20px、today 的小件 8px、plan 混合——**没有圆角阶梯**。
**建议**：统一为 4 级——大卡片 `16px`、卡片内分组 `12px`、按钮/输入 `8px`、标签/胶囊 `full`。settings 的 20px 回退 16px；today 的 8px 小件升 10-12px（8px 用在按钮上偏"硬"）。

### 2. 一处 WCAG 对比度不达标（AA 失败）
实测 plan 页「1 条想法」标签：绿色文字 `#16a34a` on 浅绿底 `#f0fdf4`，**对比度 3.15:1**（标准要求正文 ≥4.5:1）。
**建议**：绿色系小标签文字统一加深到 `#15803d`（5.5:1 达标）；同理检查全部 success 系标签（today 的"剩余 X 分钟"绿字、review 的绿色百分比都在临界区）。

### 3. 品牌靛蓝 #6366f1 与 AI 紫 #7c3aed 视觉上分不清
像素分析显示全站彩色只有 2-4%，而这少量彩色里，品牌色（靛蓝 #6366f1）和 AI 语义色（紫 #7c3aed）**在屏幕上几乎无法区分**（色相差仅 ~15°）。用户之前抱怨"紫色太紫"本质就是这个：AI 元素、实践类任务、Focus Card 完成按钮、进度条全部挤在"蓝紫"区间。
**建议**：二选一——① AI 语义色换成更明确的紫色/品红系（如 `#9333ea`→`#a21caf`），品牌保持靛蓝；② 或者反过来品牌用靛蓝、AI 用**紫红** `#d946ef`。同时给 AI 元素统一加 🤖/图标前缀，双通道区分（颜色+图标），而不是只靠色相。

## 二、P1 · 强烈建议（质感提升）

### 4. 卡片层次仍然太弱 —— 页面"平"的最大原因
像素实测：所有页面主色 `#f0f0f0` 系占 **73-80%**，卡片阴影 `rgba(0,0,0,0.04)` 1px 偏移（肉眼几乎不可见），卡片白 vs 背景 #f8fafc 亮度差仅 3%。
**建议**（三选一，推荐组合）：
- 阴影加一层：`0 1px 2px rgba(0,0,0,0.04) + 0 4px 12px rgba(0,0,0,0.06)`（悬浮感）
- 或卡片加 0.5px 更深的边框 `#d8dde4`（当前 #e5e7eb 太浅）
- 或页面背景降一档到 `#f1f5f9`（让白色卡片跳出来）

### 5. 页面密度失衡：today 空得像白纸，plan 挤得像表格
实测密度：today 57 个元素/269 字符（很空），plan 156 个元素/327 字符（很密）——**同一系统密度差 3 倍**。
**建议**：
- today：空态不该是"白纸"，给空态加引导（卡片虚线框 + "去 Inbox 倒进来"插画式引导）；区块之间加大呼吸（状态条/路线/AI 面板之间 24-32px 间距）
- plan：周历本身密是合理的，但**头部工具区**（高效时段/聚焦按钮/周头）三行信息挤在一起，建议合并成一行工具条

### 6. settings 与全站视觉割裂
settings 8 张大卡全 20px 圆角 + 标题 16px，其他页面 14px——settings 像"另一个产品"。
**建议**：圆角 20→16px；卡片标题 16→14px（与 today/plan 区块标题一致）；折叠卡的分组间距统一。

### 7. today 头部信息过载
实测头部一行塞了：问候语（24px）+ 日期 + 已完成数 + 专注分钟数 + 布局提示条——信息多但无层级。
**建议**：问候语独立一行（24px 大标题），统计信息（已完成/专注）做成两个小数字徽章放右侧，布局提示降级为 hover 或移除（设置页已有）。

## 三、P2 · 可选优化（打磨细节）

### 8. 空态设计
inbox 空输入态、today 空任务态、review 空数据态目前都是"一行灰字"。建议给三个空态配统一视觉：品牌渐变圆角图标 + 主文案 + 次文案 + 引导按钮（Inbox→"写点什么"、Today→"去 Inbox/Plan"、Review→"去 Today 专注"）。

### 9. 进度条与统计的视觉语言
全站进度条轨道都是 `#f3f4f6`（4px 高），太细太淡。建议轨道 `#e5e7eb`、高度统一 6px、填充色带 2px 圆角——进度条是"成就感"的表达，值得用心。

### 10. 侧栏深紫黑与内容区浅白的"两极分化"
侧栏 #1b1833（16% 面积）vs 内容 80% 浅灰白，对比极强。这是可接受的高对比风格，但建议：侧栏底部用户区加一点品牌渐变点缀（头像环用 brand-500→purple 渐变），让深色区域也有"色彩呼吸"。

### 11. AI 执行条样式（today Focus Card 内）
紫色横条"AI 执行"与卡片内其他元素对比过强。建议改为淡紫底 + 紫色左边条 + 图标，弱化为"提示条"而非"色块"。

### 12. 移动端未审计项
本次未测移动视口。建议后续单独过一遍（底部胶囊导航 64px tab 宽度在 375px 屏是否放得下 4 个）。

## 四、建议优先级与工作量

| 优先级 | 项 | 工作量 |
|---|---|---|
| P0-1 | 圆角阶梯统一（4 文件 CSS 类） | 0.5h |
| P0-2 | 绿色标签对比度加深 | 0.5h |
| P0-3 | 品牌/AI 色相分离（token 级） | 1h（需视觉确认） |
| P1-4 | 卡片阴影/边框层次 | 0.5h（token 级） |
| P1-5 | today 空态引导 + 密度调整 | 1-2h |
| P1-6 | settings 视觉对齐 | 0.5h |
| P1-7 | today 头部重组 | 1h |
| P2-8~11 | 空态三件套/进度条/侧栏点缀/AI 条 | 2h |

**我的建议**：先做 P0 三项（半天内），页面立刻"统一"；再做 P1-4（阴影）和 P1-6（settings），观感提升最明显。P2 随手做。
