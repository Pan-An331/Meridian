# Task OS · UI 设计稿逐页核对报告

> 核对人：UI Designer · 日期：2026-08-02 02:57-03:10
> 核对范围：UI示例/ 六份设计稿 vs 当前实现（真实渲染审计 + 代码抽查）
> 结论：**总体匹配度高（约 85%），但存在 3 处结构性缺失和若干细节差异**；字号规格已按用户要求全局放大

---

## 〇、重要发现：设计稿字号本身就是"缩小规格"

逐份提取设计稿 CSS 字号：**无任何 scale/zoom**，设计稿字号就是真实值——正文 9-12px、标题 17-22px、计时器 26px。也就是说：
- 之前实现"忠实还原"了设计稿字号 → 用户觉得"看着费力"是必然的
- **本次已按用户要求全局放大**（详见第六节）：正文 12→14px、辅助 11→12px、按钮 13→14px、页面标题 22→24px、卡片标题 17→18px
- 渲染复验：五页面溢出 0 处，14px+ 元素占比大幅提升

## 七、差异清单汇总（按优先级）

### 结构性缺失（建议补）
1. **SVG 圆环计时器**（Today 计时型 + FocusCard 两栏计时型）—— 设计稿核心视觉，当前为纯文本
2. **Focus Card 轮播**（←→ + 圆点，三型切换）—— 当前单卡
3. **AI 调整助手底部输入框**（"排期与重规划"对话输入）—— 当前只有建议列表
4. **Review 战报增强**："本周主色"格 + "发现"条 + 本周/本月分段

### 细节差异（可选）
5. Plan 本周截止：badge 计数 + 展开子任务/时间轴面板
6. Plan 任务块 AI/截止角标
7. Inbox 移动端语音条（演示概念，可不做）
8. Focus Card 右上三点菜单的备注功能

### 已对齐项（无需动）
- 导航壳（侧栏/顶栏/移动导航）、宽度规则、页面标题层级
- Inbox 全流程、Setting 全组、Plan 周历主体、Review 洞察/日记/建议
- 分类色表、时段分区（本次已补）、卡片三件套、字号层级（本次已放大）
