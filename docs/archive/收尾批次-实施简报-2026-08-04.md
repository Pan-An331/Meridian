## A · 续排按钮「明天继续」

**A1 · Plan 页续排建议条（必做 ✅）** `src/app/(dashboard)/plan/page.tsx`
- 新增 `ContinuationBar` 折叠条，位于**收集箱上方**（参考本周截止折叠条交互：默认收起，露 badge「N 个续排」，无续排显示「无」）
- 数据：`GET /api/plan/continuations`（组件挂载 + 复制成功后局部更新）
- 展开后每项：任务名 + 上次时段（昨天/今天 HH:MM-HH:MM，`fmtRange` 工具）+ 建议明天时段（HH:00 + 时长）+ 「复制到明天」按钮（busy 态防重复）
- 点按钮 → `POST /api/tasks/[id]/action {action:"continue_tomorrow"}` → toast「已排到明天 HH:00 · 任务「XX」」+ 该项移出列表 + `load()` 刷新周历（明天出现同时间段块）
- 空态：「没有需要续排的任务 🎉」
- Plan 页新增轻量 toast（fixed 底部，2.6s 自动消失）

**A2 · Today Focus Card「明天继续」次级按钮（增强 ✅）** `FocusCardV2.tsx` + `today/page.tsx`
- 主按钮旁新增次级按钮「明天继续」（白底 + 品牌色文字 + 品牌描边，未出发/进行中态显示）
- 点击 → 同 action → toast「已排到明天 HH:00 · 明天见」

## B · 忘记确认提示条 ✅（FocusCardV2.tsx）

- 判断：`card.departureAt` 存在 && 未完成（phase ≠ done）&& `now − departureAt ≥ 4 小时` → 动机行下方警示条
- 文案：「⏰ 已出发 X 小时没回来确认 —— 做完了？」+ [补记完成] [还在做，继续]
- **「补记完成」→ 复用现有 `finishFlow`**（补记时长弹窗默认 = 现在 − departureAt，已有逻辑零改动）
- **「还在做，继续」→ session 级关闭**（`reminderDismissed` state，不做持久化）
- 样式：琥珀底 `#FFFBEB` + 金色左边条 `var(--v2-brand-gold)` + 13px，不抢主按钮视觉；demo/真实卡均生效

## C · 左栏项目阶段直读树接口 ✅（today/page.tsx，去 mock）

- **零后端改动**：`GET /api/projects/tree` 页面级 fetch 一次 + `treeCache` state（不随卡片刷新重复请求）
- 祖先链匹配：后端 `currentTask.parentTitle` 已是完整归属链（"根 / 阶段"格式）→ `matchChain` 按名称路径在树中逐级匹配（找不到 = 孤儿 → stages 空，现有渲染位已处理空态）
- `stages` = 链上 project/phase 级节点 `{name, done: status==='completed', current: 最后一级}`；`projectProgress` = 最近一个有子级的祖先完成度（**树接口 `doneCount/totalCount` 优先，前端递归兜底**——后端聚合字段就绪后自动消费）
- `CurrentTask` 接口预留 `parentId?`（后端返回后可按 id 精确匹配）

## D · 积累·每日卡 mini-cal ✅（FocusCardV2.tsx）

- 新增 `MonthCal` 组件：**7 列网格（周一开头）**显示当月 1-N 号；打卡日**金色圆底白字**（`var(--v2-brand-gold)`）、**今天品牌色描边**、其他灰字；顶部「本月 Y 年 M 月 + 打卡 N 天」小标
