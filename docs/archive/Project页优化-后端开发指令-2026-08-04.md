## 1. 背景

Project 页视觉重构（前端并行），后端提供 4 个新增数据能力。**现有树/孤儿/streak 接口结构不动，只加字段**。

---

## 2. 阶段 A：项目派生色（`themeColor`）

**需求**：项目分组头颜色 = 项目挂的主题 > 项目下任务主领域，自动聚合，前端零计算。

### 改动点：项目树接口（返回树数据的路由，如 `GET /api/projects/tree` 或 views 接口）

每个 **project 级节点**新增字段：

```ts
themeColor: { pcolor: string; pbg: string; theme: string | null } | null
```

**聚合规则（纯函数，零 LLM 依赖）**：
1. 统计该项目下所有任务（含子级）的 `theme` 计数 → 取最高频 theme
2. 命中 → `pcolor/pbg` 取 THEMES 表对应色（竞赛 #DB2777/#FDF2F8、考研 #F97316/#FFF7ED 等）
3. 无 theme → 按 `category`（领域）主频 → 取领域色表对应色
4. 都无 → `null`（前端用品牌蓝兜底）

**建议**：聚合逻辑抽到 `src/lib/project/theme-color.ts` 纯函数（可单测），接口调用。

---

## 3. 阶段 B：待整理池 AI 建议归属（`suggestion`）

**需求**：孤儿任务（未挂树 task）每项返回"建议挂入目标"，前端一键挂入。

### 改动点：孤儿列表接口（orphans 数据所在路由）

每项孤儿新增：

```ts
suggestion: { targetId: string; targetTitle: string; reason: "title-match" | "theme-match" | null } | null
```

**匹配规则（零 AI 底线——先规则后可选 LLM）**：
1. **标题匹配**：孤儿标题包含某个项目/阶段名关键词 → 建议挂入该节点
2. **主题匹配**：孤儿 theme 与某项目 theme 一致 → 建议挂入该项目
3. 匹配不到 → `null`（前端显示"拖拽归位"提示，不强猜）

> ⚠️ 遵守产品红线：**拿不准返回 null，不硬给建议**（与 parser/theme 的保守原则一致）。

---

## 4. 阶段 C：完成度数据

**需求**：树节点行尾显示 `3/6`、`2/5`、`12天`。

- 确认现有树接口是否已返回每节点的 `doneCount/totalCount`（子任务完成数/总数）
- 没有 → 补：项目/阶段节点聚合直接子级完成数；积累型返回 `streak.current` 与 `weekCount/weekTarget`（streak 数据若已有则直接透传）
- **前端只消费，计算放后端**（避免前端重复遍历）

---

## 5. 阶段 D：★ 清单开关持久化

**需求**：前端点 ★ 切换"执行清单"状态，需持久化。

### 改动点：`PUT /api/tasks/[id]`

- 复用/新增字段标记"可排期执行清单"：建议直接用现有 `star` 语义或新增 `isExecutable Boolean @default(false)`（**schema 改动前与产品确认字段名**；若选 star 则零 schema 改动）
- ★ 开关 = 写该字段；Today 的 currentTask 判定逻辑如需联动该标记，一并确认（本期可只持久化，不强制联动）

---

## 6. 阶段 E：验证

- `tsc --noEmit` 零错误
- vitest：themeColor 聚合 + suggestion 规则各补单测（纯函数，好测）
- API 冒烟：树接口返回 themeColor / orphans 返回 suggestion / tasks PUT 写 ★ 字段
- 现有 81 用例不回归

## 7. 验收标准

- [ ] 树接口 project 节点返回 themeColor（theme 优先、领域兜底、null 可）
- [ ] orphans 返回 suggestion（标题/主题匹配，拿不准 null）
- [ ] 完成度字段就绪（doneCount/totalCount 或确认已有）
- [ ] ★ 持久化可用
- [ ] 新增单测通过 + 81 用例不回归
- [ ] tsc / 冒烟过

---

## 8. Non-goals

- ❌ 不引入 LLM 依赖做建议（先规则；LLM 增强留 Next 阶段）
- ❌ 不改树结构/任务核心字段（只加读字段）
- ❌ 不做手动选色（颜色全部从 THEMES/领域表派生）
