## Bug 1 · 无法取消勾选 ✅

**文件**：`src/app/(dashboard)/today/page.tsx` `toggleChildItem`
- **根因**：勾选子项只调 `action:"complete"`，已完成项再点无动作
- **修复**：按子项当前状态选择动作——`item.done ? "reopen" : "complete"`（后端 `reopen` 已存在，清 completedAt）
- **验证**：Today 清单勾选 → 再次点击 → 取消完成态（done 由 completedAt 推导，刷新后保留）

## Bug 2 · 完成状态不同步 ✅

**文件**：`src/app/api/tasks/[id]/action/route.ts` `complete` 分支
- **根因**：complete 只补记时长 + 完成任务，执行清单当前项不勾选
- **修复**：complete 时自动完成**第一个未完成子任务**（= 当前高亮项，按 sortOrder asc）——"标记完成"时执行清单与专注时间一起更新
- **验证**：清单型任务点「该项完成」→ 当前项勾选 ✓ + 时长补记；刷新保留

## Bug 3 · 跳过逻辑错误 ✅

**文件**：`src/app/api/tasks/[id]/action/route.ts` + `src/app/(dashboard)/today/page.tsx`
- **根因**：`onSkip → action:"reschedule"` → 后端 `deleteFutureSchedules`（把排期全删 = "从具体安排移除"）+ 误伤项目状态
- **修复**：新增 `action:"skip_item"`——只把当前未完成项 `sortOrder` 置为同组最大 +1（**顺延到清单末尾**，继续下一项）；不删任务、不动排期、不触发完成联动；前端 onSkip 改传 `skip_item`
- **验证**：点「跳过后一项」→ 该项移到底部，下一项高亮；Plan/Project 无任何变化
