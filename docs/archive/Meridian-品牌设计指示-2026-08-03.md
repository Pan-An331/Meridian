# Meridian · 子午 品牌设计指示（转交 UI 设计师）

> 版本：2026-08-03 · 产品经理签发
> 用途：UI 设计师出品牌初稿（Logo + 品牌色），供产品验收后实施

---

## 1. 背景与品牌故事（设计前提）

- 产品：**Meridian · 子午**——AI 驱动的个人时间操作系统（成长系统：输入→规划→执行→复盘）
- 品牌故事（必须体现在设计中）：
  - **子午线（Meridian/经线）= 方向**：帮用户过滤未来、知道该做什么
  - **正午（Meridian 古义）= 时间**：专注当下，每一天围绕用户的中轴运转
  - Slogan：**「你的时间，自有中轴」**
- 现有产品基调：浅灰底 + 白卡、圆角卡片、memo 黄清单（已有 v2 设计系统），品牌色需与现有 UI 兼容

## 2. Logo 设计任务

### 2.1 核心概念（概念板）

**子午线的图形本质 = 一个圆 + 一条中轴线**。圆（地球/时钟/成长闭环）+ 中轴线（子午线/方向轴）。

请围绕此概念出 **4 个变体初稿**（不必都做精，线稿级即可供挑选）：

| # | 变体名 | 构成要素 | 语义 |
|---|--------|---------|------|
| 1 | **中轴** | 圆环 + 垂直中轴线贯穿 + 中心金点 | 最简 · 子午线图形本质 |
| 2 | **日晷** | 时钟圆环（刻度）+ 金色指针指向上（正午） | 时间语义最强 · 呼应 Meridian=正午 |
| 3 | **准星中轴** | 圆环 + 垂直中轴 + 水平短准星线（十字）+ 金心 | 时间 × 聚焦（瞄准此刻） |
| 4 | **经线球** | 圆 + 垂直经线 + 水平纬线（地球仪） | 子午线地理本义（备选，偏教育感） |

### 2.2 风格要求

- 几何极简、线条克制、现代高级感（参考 Notion / Arc / Linear 的品牌感）
- 允许极细微渐变，禁止拟物、卡通、多色堆砌
- **favicon 16px 小尺寸必须可识别**（中轴线粗细 ≥ 圆环粗细，避免细线糊掉）
- 圆环闭合感重要（呼应"成长闭环"）

### 2.3 交付物（每个变体）

- 主 Logo 图标版（SVG + 512px PNG）
- 横向带字版（Meridian + 子午 中文小标，SVG）
- favicon 全套：16 / 32 / 48 px（PNG + ICO）
- 侧栏小标 24px、登录页大标 96px 应用示意

## 3. 品牌色设计任务

### 3.1 三套候选色板（全部渲染完整版，供产品选）

| 套 | 主色 | 强调色 | 故事 |
|----|------|--------|------|
| **A · 子午**（推荐方向） | 子夜蓝 `#1E3A8A` | 正午金 `#F59E0B` | 子时沉淀（深蓝专注）、午时发光（金色完成）——颜色讲和名字一样的故事 |
| B · Indigo 延续 | `#6366F1` | `#4338CA` | 保持现有品牌色，零风险（对照组） |
| C · 午夜青 | `#0F2A43` | `#06B6D4` | 冷静科技感（对照组） |

### 3.2 每套色板必须输出（token 级）

| token | 用途 |
|-------|------|
| 主色 brand | 主按钮 / 主链接 / 选中态 / 导航高亮 |
| 主色深 brand-deep | hover / 按压态 |
| 主色浅 brand-bg | 选中背景 / 徽章底 |
| 强调色 gold（A 套新增） | Logo 中轴 / slogan 点缀 / 打卡完成瞬间（仅 A 套需要） |
| 中性色 | 页面底 / 卡片底 / 边框 / 文字 2-3 级（沿用现有 v2 中性色即可，标注确认） |

### 3.3 应用预览（每套都要出，用户看完效果再选）

- 登录页首屏（左侧品牌区 + 右侧表单，参考现有登录页布局）
- 主按钮 + 链接 + 导航高亮 3 个元素的应用效果
- 与现有页面（浅灰底 + 白卡 + memo 黄清单）的兼容性检查说明

## 4. 交付格式与时间

- 格式：HTML 视觉稿（自包含，浏览器直接打开）或 Figma 链接均可；HTML 优先（项目惯例）
- 每份视觉稿内附：4 个 Logo 变体（含 favicon 效果）+ 3 套色板（含应用预览）
- 完成后交产品验收：**产品选定 logo 变体 + 色板 → 前端实施（token 替换 + 登录页 + favicon）**

## 5. 明确不做（Non-goals）

- ❌ 不改产品内已定设计系统（卡片圆角/间距/memo 黄清单/领域 7 色/主题色）
- ❌ 不做动效 logo（后续可加，本期静态）
- ❌ 不做吉祥物/插画体系
- ❌ 品牌色只影响 brand token 系，不重涂领域色
