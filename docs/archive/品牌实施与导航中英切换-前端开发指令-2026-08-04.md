## 2. 阶段 A：品牌色 token（globals.css）

```diff
-  --v2-brand: #6366f1;        /* 品牌（全站唯一主色） */
+  --v2-brand: #1e3a8a;        /* 子夜蓝（品牌主色） */
+  --v2-brand-deep: #172554;   /* hover/按压 */
+  --v2-brand-bg: #e0e7ff;     /* 选中底/徽章底 */

```

> 全站 `--v2-brand` 系引用自动生效（主按钮/链接/导航高亮/周历选中），**其余领域 7 色/主题色/memo 黄不动**。

## 5. 阶段 D：导航中英切换（核心新功能）

### D1 `src/lib/navigation.ts`

- label 改为可切换：`{ href, key: "inbox", labelZh: "收纳", labelEn: "Inbox", ... }`
- 导出 `navLabels(lang)` 或渲染时按设置取值；**URL 路由不变**

### D2 设置项

- 设置页新增「导航显示」：中文 / 英文（单选）
- 存储：localStorage（`meridian.navLang`）即可，**不用动数据库**（轻量偏好）
- 默认中文

### D3 侧栏渲染

- `DashboardShell` 读取设置 → 渲染对应 label（sub 小字：中文时显示原 sub 或简化，英文时显示原 sub）

### D4 导航词（调性档定稿）

| key | 中文 | 英文 |
|-----|------|------|
| inbox | 收纳 | Inbox |
| plan | 蓝图 | Plan |
| today | 此刻 | Today |
| review | 复盘 | Review |
| projects | 项目 | Project |
