# 全站移动端适配优化 · 实施简报（2026-08-04）

> 角色：FrontendDeveloper · 重点：Plan 页 · 验证：375px 设备模拟器（Playwright 无头 Chromium）+ 布局断言
> 依据：《收尾批次-前端开发指令》+《任务信息架构规范-V3 §5》+《五页面布局重排方案》（860px 断点规范）

---

## 根因

Plan 周历每天列 `minWidth: 130px`（7 天 ≈ 910px）+ 时段列 36px + 时间列 60px ≈ 1006px，手机 375px 视口**强制横向溢出**（页面级滚动，非容器内滚动）。

## ① Plan 周历移动端模式（核心）

| 机制 | 实现 |
|------|------|
| **自动聚焦 3 列** | `matchMedia("(max-width: 860px)")` 监听：<860px 自动 `setFocus(true)` → 聚焦视图 = 今天 + 明 + 后 3 列（桌面保持用户手动选择） |
| **列宽自适应** | `.plan-week-col{min-width:0!important}`（媒体查询覆盖内联 130/140px）→ 3 列均分 375px，零溢出；桌面不受影响 |
| **窄屏缩列** | 时段标签列 36→22px、时间列 60→44px（`.plan-week-pcol/.plan-week-tcol`）；天头文字 13px（`.plan-week-txt`）；高效时段徽章窄屏隐藏（`.plan-week-gld`） |
| **触控** | 周/聚焦胶囊 py-1.5→py-2.5 + min-h-44；凌晨折叠条 py-1.5→py-2.5 + min-h-44 |

## ② 页头 / 折叠条窄屏修正

- Plan / Today / Review 页头 `flex-wrap`（窄屏标题与操作换行不挤）
- 折叠条（续排/截止/健康度）头部按钮本就 py-3 ≈44px ✓ 未动

## ③ 四页 375px 实测（Playwright 设备模拟 375×812 逐页断言）

| 页面 | scrollWidth | 溢出 | 小按钮(<40px) | 处理 |
|------|-------------|------|--------------|------|
| Today | 375 | ❌无 | 0 | 页头 wrap；AI「发送」py-1.5→py-2.5+min-h-44 |
| Plan | 375 | ❌无 | 0 | 见 ① |
| Review | 375 | ❌无 | 0 | 页头 wrap；周/月分段 py-1.5→py-2.5+min-h-44 |
| Project | 375 | ❌无 | 0 | 树行窄屏隐藏阶段徽章（`.b-stage` 隐藏、主题角标限宽 56px 省略）；＋新建项目按钮（树卡 head + 空态）均 min-h-44 |
| Inbox | 375 | ❌无 | 0 | 已达标（无溢出/无小按钮） |

> 断点规范遵循：双栏回退均按 860px（fcv2 两栏 / pt-main / plan-cal 聚焦 / row2 900 例外为既有）。

## ④ 触控优化（≥44px）

- Plan：周/聚焦胶囊、凌晨折叠条
- Today：AI 发送按钮、Focus Card 主按钮 + 「明天继续」次级按钮（py-2.5 + min-h-44）
- Review：周/月分段按钮
- Project：＋新建项目（树卡 head `pt-new-btn` 媒体查询 44px + 空态按钮 py-2.5）

## 环境备注（复验用）

- **本地 PG**：项目内便携版 `.pg-local/extracted/pgsql/bin/postgres.exe -D .pg-local/data`（沙箱外 Start-Process 分离启动；沙箱内启动会被拦截文件访问 → Permission denied）
- **dev server**：需在 PG 就绪后启动（Prisma 连接池启动时初始化，PG 晚起会缓存连不上）
- **截图脚本**：`scripts/mobile-shot.py`（Playwright，注册临时账号 → 登录 → 375px 逐页截图；模型不支持读图时用布局断言脚本替代目检）
