# Meridian · 子午 使用手册

> 你的时间，自有中轴。
> 一天有万千事物，总有一条中轴——Meridian 帮你把纷繁的任务理清、排好、执行、复盘。

---

## 一、认识 Meridian

Meridian（子午）是一个**个人成长系统**，不是普通待办工具。它围绕一条闭环运转：

```
收纳（收集想法）→ 蓝图（规划时间）→ 此刻（专注执行）→ 复盘（回顾成长）
```

核心理念：**帮用户过滤未来，不是堆积未来**。系统只在你需要时给出"现在最该做什么"，其余交给日历和时间轴。

## 二、五个页面速览

| 页面 | 导航名 | 干什么 | 什么时候用 |
|------|--------|--------|-----------|
| 收纳 | Inbox | 把脑子里的事倒进来，AI 帮你理解分类 | 想到任何事，随手记 |
| 蓝图 | Plan | 看一周日历、拖拽排期、安排截止 | 每天规划/每周规划时 |
| 此刻 | Today | 现在该做什么、出发执行、打卡 | 要开始干活时 |
| 复盘 | Review | 看本周战果、行为洞察、下周建议 | 每周日/每周总结 |
| 项目 | Project | 把任务归到项目树里、整理结构 | 任务乱时、建项目时 |

## 三、开始使用

### 3.1 第一步：注册登录
打开网址 → 注册账号（邮箱 + 密码）→ 进入主界面。个人使用建议**专用一个账号**，不要把测试数据混进正式账号（会影响复盘统计）。

### 3.2 第一步：把任务丢进「收纳」
在收纳页输入一句话，比如：

- `明天上午画四轴飞行器原理图`
- `考研数学 第三章 课后习题`
- `晚上去健身房练背`
- `背单词 Unit 12`

AI 会解析出：标题、领域分类（学习/实践/健康…）、预估时长，并弹出确认表单。**确认后任务就正式入库**。

> 💡 如果你不想让 AI 猜，点「手动创建」自己填也行。

### 3.3 理解任务的三层身份

每个任务有三个"身份维度"，各管各的：

| 维度 | 是什么 | 例子 |
|------|--------|------|
| **领域**（7 类封顶） | 任务属于哪个生活领域，决定颜色 | 课程 / 学习成长 / 专业实践 / 健康生活 / 个人事务 / 社团外部 / 未分类 |
| **主题**（自由扩展） | 任务为了什么目标，决定角标 | 考研 / 竞赛 / 身材…（收纳时可选或自定义） |
| **项目**（树） | 任务归到哪个项目下，决定归属链 | 考研 › 数学 › 第三章 |

- 领域：AI 猜 + 你确认
- 主题：目标标记（比如"备赛期"给任务挂「竞赛」主题，卡片会出现红色角标）
- 项目：在「项目」页拖拽归位

### 3.4 理解任务的形态

系统根据任务内容自动判断形态，不需要你选：

| 形态 | 特征 | 例子 |
|------|------|------|
| 固定时间型 | 有排期 | 上课 09:00-10:30 |
| 清单型 | 有子任务清单 | 画原理图（电源模块/主控 MCU/电机驱动） |
| 学习型 | 无子任务的一般任务 | 看一本书 |
| 积累·每日 | 每天打卡 | 背单词 |
| 积累·频次 | 每周若干次 | 健身（每周 3 次） |

## 四、每日使用流程

### 4.1 「蓝图」排期（前一天或当天早上）

1. 打开蓝图 → 看到本周日历（周计划）
2. 把收集箱里的任务**拖到**想做的日期和时段（或点击空白格快速创建）
3. 顶部「本周截止」折叠条能看到本周到期的任务
4. 「高效时段」徽章会提示你历史上效率最高的时段

> 💡 聚焦模式：只看今天+未来两天，卡片放大，适合快速排近三天。

### 4.2 「此刻」执行（要干活时）

打开此刻页，第一张卡就是**当下最该做的任务**（Focus Card）：

1. **动机行**（紫色）：告诉你"为什么做它"——比如"为四轴飞行器打好电路基础"
2. 点 **「出发」** → 放下网站，去干活
3. 干完回来点 **「完成」**（或清单型逐项勾选、积累型点「打卡」）→ 系统弹「刚才做了多久？」补记时长（默认=现在−出发时刻，可改）
4. 忘了回来确认？系统会在出发 4 小时后提示「已出发 X 小时没回来确认——补记完成 / 还在做」

> 💡 「明天继续」：今天做不完的任务，点「明天继续」一键复制到明天同一时段。
> 💡 「暂停」：中途被打断，点暂停并选原因（太难/注意力下降/临时有事…），系统会学习你的模式。

### 4.3 「复盘」回顾（每周一次）

打开复盘页从上往下看：

1. **本周战报**：完成了多少任务、专注多久、连续打卡
2. **指标卡**：周完成率、AI 采纳率、堆积率、打卡保持率——系统健康度
3. **主题投入**：各目标（考研/竞赛…）占本周比例 + 较上周趋势
4. **产出日记**：每天做了什么
5. **本周洞察 + 下周建议**：AI 总结行为模式，给出可应用的改进建议（比如"把深度工作排到上午 9-11 点 → [应用]"）

### 4.4 「项目」整理（每周或每月一次）

1. 左侧是**项目树**：项目（分组头）→ 阶段 → 任务，带连接线显示归属
2. 把散落的任务拖进对应的项目（待整理池会给出"AI 建议挂入 XX"）
3. 点 ★ 可以把某节点设为「执行清单」
4. 右侧习惯区：所有积累型任务的打卡都在这（唯一入口）

## 五、常见操作速查

| 我想… | 怎么做 |
|--------|--------|
| 快速记一个任务 | 收纳页输入一句话 → AI 确认 |
| 改任务时间 | 蓝图页拖拽时间块 / 点开档案面板改 |
| 改任务分类/主题 | 点任务卡片 → 档案面板 → 身份区编辑 |
| 把任务归到项目 | 项目页拖到树上（或待整理池一键挂入） |
| 今天做不完 | 此刻页点「明天继续」 |
| 忘了打卡/确认 | 回来点完成/打卡，系统会补记时长 |
| 看某个任务的完整信息 | 任何页面点任务卡片 → 档案面板（五层信息：身份/结构/时间/执行/AI） |
| 找某个任务 | 顶部全局搜索框 |
| 导出我的数据 | 设置页 → 导出（JSON 带版本号，可迁移） |
| 切换导航语言 | 设置页 → 导航语言（中文/English） |

## 六、概念澄清

- **任务 ≠ 时间**：任务本身没有时间，时间在日历上。改时间永远在蓝图页操作。
- **卡片三层**：任何任务卡片只显示 身份（标题/类型/颜色）→ 时间（排期/截止）→ 状态（进度/打卡），更多信息点开详情看。
- **AI 的角色**：AI 帮你解析、建议、总结，但**所有决策权在你**——排期是你拖的、分类是你确认的，AI 只建议不强制。

## 七、隐私与数据

- 数据保存在你的账号下，设置页可一键导出全部数据（带版本号的 JSON，方便以后迁移）
- 无任何第三方广告或数据共享
