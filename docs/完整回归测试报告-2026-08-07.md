## 6. 残留风险（如实列出）

1. **浏览器覆盖**：仅在 Chromium 验证（R4 要求的"主要浏览器"未完全满足——Playwright 配置仅含 chromium project）。Firefox/WebKit 未跑，跨浏览器差异未覆盖。
2. **设备尺寸**：使用 Desktop Chrome viewport（1280×720 默认），**未覆盖移动端/窄屏**（<860px 单栏布局未验证）。
3. **条件跳过 8 项**：P1/P9/P10/T9/R3/R5/J9/S1 按运行数据条件跳过，对应交互（周/聚焦切换、凌晨折叠、健康分、AI 助手建议、产出日记、记忆写入、排序按钮、昵称修改）未被断言覆盖，需在对应数据场景下手动验证。
4. **性能抖动**：Neon 高延迟（单请求 2-5s）下个别用例仍存在首跑超时风险（retries=1 兜底已生效）；已通过 waitForResponse/轮询+宽超时缓解，但极端网络下仍可能触发重试。
5. **AI 用例**：E2E 默认走规则降级（确定性）；真实 LLM 链路（E2E_WITH_AI=1）未做全量回归，AI 返回质量类问题不在此报告覆盖。
6. **遗留待办（非本报告范围）**：BUGS.md 待修复区 6 条（?highlight 跳转断链 / today-refresh 未消费 / plan-repeat 未接线 / Review 周环比前端显示"—" / Focus Card 左栏 mock / ai/today.ts 遗留），均不影响本次回归功能。
