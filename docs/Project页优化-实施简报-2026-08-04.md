## 阶段 B · 交互

| # | 交互 | 实现 |
|---|------|------|
| B1 拖拽 | HTML5 DnD 三区：拖到中间 1/3 = 子级（`drag-over-child` 蓝虚线框，`moveNode` 改 parentId）；拖到上/下 1/3 = 换序（`drag-over-before/after` 金色插入线，同级 sortOrder 重排）；循环防护（不能挂自身子树）；drop 后重算连接线 + toast；待整理池项可拖入树成子级 |
| B2 新建 | 右上「＋新建项目」（根）+ 行尾 hover「＋」（子项）→ 树顶 inline input（`pt-new-input`，Enter 创建 / Esc 取消）→ 自动挂父级 + 自动层级（项目下=阶段、阶段下=任务） |
| B3 ★ 清单开关 | 点 ★：`starSet` 乐观 Set 切换 + `is-list` 类 → 「执行清单」徽章显隐；同步 PUT `{ star }`（后端 star/listFlag 就绪后落库，当前静默忽略——PUT 白名单外字段不报错） |
| B4 展开收起 | ▾/▸ 切换 `expanded` state 集合，子树显隐 + 连接线重算 |
| B5 hover 操作钮 | 行尾 ＋ / ↑ / ↓ 仅 hover 显示（`pt-opts`） |

## 阶段 D · 档案面板 + 派生色

- **档案面板**：点任意树节点 → `useArchive().open(taskId)`（全局 560px 档案面板，Plan/Search 同款，归属链/元信息/memo 清单/AI 增强）
- **派生色消费**：`TreeNode.themeColor?: {color,deep,bg}`（契约字段，后端就绪后直接消费，前端不做颜色计算）；当前后端未返回 → 前端 fallback：`node.theme` → THEMES 预设 → `resolveTheme` 标题推断 → 领域色（`nodeTheme()` 工具，零手动选色）

## 遗留 / 说明

- `themeColor` / `theme` / `suggestion` / `star` 均为**契约预留字段**：后端就绪后前端自动消费（派生色、AI 挂入建议、★ 持久化），无需再改 UI 逻辑
- 打卡从树行移除 → 习惯区唯一入口（树行仅金色状态点，点击提示"打卡在右侧习惯区"）
- 拖拽"成为子级"不改 `level`（后端 move 仅改 parentId；层级由创建类型决定，符合 Non-goal「不改业务数据模型」）
- 新建自动层级：项目根下 = 阶段、阶段下 = 任务
