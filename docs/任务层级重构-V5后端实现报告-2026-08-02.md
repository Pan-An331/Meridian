## 六、UI 对接要点（开发预览版用）

1. **Today 卡片 children 字段升级**：`{ id, text, done, group, noteStep, self }`
   - `noteStep: true` → 备注拆行（勾选状态存 localStorage，key `taskos.note-steps.<taskId>`，不写库）
   - `self: true` → 任务自身一行（勾选=调 complete）
   - 真实子级 → 勾选调 action complete（会触发父联动）
2. **积累型卡片**：currentTask 有 `accumulate: true` + `streak { current, longest, lastDate, todayChecked, last30 }` → 渲染打卡按钮 + 连续天数 + 30 天点阵；打卡调 POST checkin（返回新 streak）
3. **项目整理页**：GET tree 渲染树（展开/折叠/缩进）；右侧池 = orphans；拖拽调 POST move（newParentId 为目标节点 id 或 null 移出树）；节点菜单：level 切换（PUT tasks/[id]）、积累开关
4. **明天继续**：任务卡按钮调 action continue_tomorrow；Plan 页顶部可拉 GET continuations 展示建议列表，一键确认
5. **Plan 周历**：scheduledTasks 有 accumulate 标记 → 积累型每天一块可特殊渲染

## 七、已知边界

- 归属链上限 5 级截断（防异常循环）
- 积累型默认 20:00 重复排期（可改 hour 参数）；重复排期 30 天
- 备注拆行勾选是前端本地状态，换设备不同步（设计如此）
- autoCompleteParents 无反向联动（reopen 不回滚父状态，已确认）
