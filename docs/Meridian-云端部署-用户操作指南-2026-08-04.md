## 第 1 步：推 GitHub（5 分钟）

```bash
# ① 浏览器打开 github.com → 登录 → 右上角 + → New repository
#    名称填 meridian（或任意）→ 选 Private（私有）→ Create

# ② 回到项目目录（G:\Agent_Project\task-manage-sys），执行：
git remote add origin https://github.com/<你的用户名>/meridian.git
git push -u origin master
```

完成标志：GitHub 网页上能看到代码仓库。

---

## 第 2 步：建 Neon 免费库 + 导数据（10 分钟）

```
① 浏览器打开 neon.tech → Sign up（可 GitHub 登录）→ Create Project
   （免费版 0.5GB，区域选 US East 或 Singapore 都行）
② 项目创建后，复制 Connection String：
   postgresql://<user>:<pass>@ep-xxx.aws.neon.tech/neondb?sslmode=require
③ 数据导入（本地 PG 已验证，任选一种）：
   A. 改 .env 的 DATABASE_URL 为 Neon 连接串，然后执行：
      node scripts/migrate-sqlite-to-pg.mjs   （脚本幂等，可重复跑）
   B. 或用 pg_dump 导出本地 PG → psql 导入 Neon
④ 验证：Neon 网页控制台 → SQL Editor 里跑：
      SELECT COUNT(*) FROM "Task";   -- 应为 45（或你实际任务数）
```

完成标志：Neon 控制台能看到数据。

---

## 第 3 步：Vercel 部署（10 分钟）

```
① 浏览器打开 vercel.com → Sign up（GitHub 登录即可）→ Add New Project
② Import 你刚推的 GitHub 仓库（meridian）
   - Framework 自动识别 Next.js，构建命令不用改
③ 环境变量（Project Settings → Environment Variables）：
   DATABASE_URL    = 第 2 步的 Neon 连接串
   AUTH_SECRET     = 随机串（可运行 openssl rand -base64 32 生成，或随便编一串长的）
   AUTH_TRUST_HOST = true
④ 点 Deploy → 等 1-2 分钟 → 完成
   地址形如：https://meridian-xxx.vercel.app
```

完成标志：打开 https://meridian-xxx.vercel.app 能见到登录页。

## 踩坑提醒

| 坑 | 应对 |
|----|------|
| push 报错"remote origin already exists" | `git remote set-url origin https://github.com/<用户名>/meridian.git` |
| Neon 连不上 | 连接串必须带 `?sslmode=require`；区域选错可重建 |
| Vercel 构建失败 | 大概率环境变量没填全（三个都要）；distDir 已注释无需担心 |
| 登录后没数据 | DATABASE_URL 可能指到了空的 Neon 库 → 重跑迁移脚本 |
