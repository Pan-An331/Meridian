# Meridian 登录页品牌文案规格（转 UI 设计师）

> 版本：2026-08-03 · 产品经理签发 · 品牌定稿：Meridian · 子午
> 用途：UI 设计师按本文案规格重做登录页视觉稿；本规格同时约束产品内品牌展示点

---

## 1. 品牌文案三层结构（核心原则）

**产品已定稿 slogan 双层结构**——大品牌感 + 伴随解释，缺一不可：

| 层 | 文案 | 职责 | 出现位置 |
|----|------|------|---------|
| ① 主 Slogan | **你的时间，自有中轴。** | 品牌调性（大品牌感、抽象、有味道） | 登录页大标题 + 设置页关于 |
| ② 解释句 | **一天有万千事物，总有一条中轴。** | 让"中轴"落地（解释什么是中轴） | 主 Slogan **正下方**，永远伴随 |
| ③ 品牌故事段 | 子午为向，正午为时——把脑海里的纷繁交给 Meridian，每一天围绕真正重要的事物运转。 | 定义（子午双义）+ 功能（产品做什么） | 登录页品牌区正文 |

> **为什么双层**：主 Slogan 抽象是刻意的（大品牌感），但抽象必须有解释伴随——"中轴"不解释用户会问"什么是中轴/为什么是时间中轴"。解释句「万千事物，总有一条中轴」用"万千 vs 一条"的对比让中轴有了着落，同时暗示产品核心动作：**从纷繁里帮你挑出主线（过滤未来）**。

## 2. 登录页文案完整排布

### 2.1 品牌区（左侧，深蓝渐变背景，参考现有视觉方案）

从上到下：

| 元素 | 文案 | 字号/样式建议 |
|------|------|--------------|
| Logo | 图标 + Meridian + 子午 | 图标 40px + 品牌名 20px 白字 |
| 主 Slogan | **你的时间，自有中轴。** | 30px 白字，800 字重，可拆两行 |
| 解释句 | 一天有万千事物，总有一条中轴。 | 15px，白 72% 透明度，主 slogan 正下方 |
| 品牌故事段 | 子午为向，正午为时——把脑海里的纷繁交给 Meridian，每一天围绕真正重要的事物运转。 | 13.5px，白 60%，最多三行，行距 1.8 |
| 装饰 | 中轴 logo 大图水印（右下角，低透明度） | 可选 |

### 2.2 表单区（右侧，白底）

| 元素 | 文案 | 备注 |
|------|------|------|
| 标题（登录） | 欢迎回来 | 18px 700 |
| 标题（注册） | 开始你的子午 | 同上 |
| 输入框占位 | 邮箱 / 密码 | 浅灰占位文字 |
| 主按钮 | 进入子午 → | 主色底白字 |
| 辅助 | 忘记密码？ / 没有账号？注册 | 浅灰链接 |
| 页脚 | AI 驱动的个人时间操作系统 · © 2026 Meridian | 10.5px 浅灰 |

### 2.3 浏览器/页面标题

- 浏览器标签：`Meridian · 子午`
- metadata description：`AI 驱动的个人时间操作系统——把脑海里的纷繁整理成可执行的时间系统，每一天围绕真正重要的事物运转。`

## 3. 产品内品牌展示点（同规格约束）

| 位置 | 内容 |
|------|------|
| 设置页「关于」 | Meridian · 子午 / AI 驱动的个人时间操作系统 / 版本号；可附解释句「一天有万千事物，总有一条中轴」 |
| Today 空态（可选） | 保持克制，不强行塞品牌文案；如需要可用解释句变体：把脑海里的事倒进收集箱，中轴自会浮现 |
| 侧栏 | 导航显示名中文化：收集/规划/今日/复盘/项目（URL 不变）；侧栏顶部品牌名 Meridian |

## 4. 视觉稿要求（UI 设计师）

1. 按 §2 文案逐字落位，**主 Slogan 与解释句的相对位置不可拆分**（解释句必须紧贴主 slogan 下方）
2. 品牌区深蓝渐变背景 + 白色文字（配色方案待定：子午蓝金 / Indigo / 午夜青三选一，三套都出）
3. 表单区干净白底，与现有登录页结构一致
4. Logo 变体（中轴/日晷/准星中轴/经线球）在品牌区上方各出一版效果
5. 移动端：品牌区收窄为顶部横幅（主 slogan + 解释句保留），表单区下方

## 5. 明确不做（Non-goals）

- ❌ 不新增第三层 slogan（文案三层封顶，防堆砌）
- ❌ 品牌故事段不做"轮播/动态切换"（静态两行即可）
- ❌ 不在表单区塞品牌文案（表单区保持功能性）
- ❌ 不动产品内其他页面文案（仅登录页 + 设置页关于 + metadata）
