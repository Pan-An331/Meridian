## 一、Today 页（3 项）

### P1-1 · 「今日路线」缺少"提前执行"能力
**现象**：完成当前任务后只能"空等"下一个排期，无法提前开始。
**根因**：今日路线按排期顺序展示，无"提前执行"入口。
**建议**：
- 路线项 hover 出现「提前执行」按钮 → 调用现有 action（如 `start`），把当前任务标记为进行中
- 或提供「跳过等待 → 直接开始下一项」
- 落点：today/page.tsx 的今日路线列表项

### P1-2 · 卡片「预计 0 分钟 / 已用 0 分钟」显示异常 + 显示"闲"字
**现象**：未排期/未开始的任务显示"预计 0 分钟、已用 0 分钟"，卡片信息很空；某处出现"闲"字。
**根因**：
- 无排期任务 `plannedMinutes=0` → 显示"0 分钟"（数据缺失的展示缺陷）
- "闲"字在 plan/page.tsx:311（周历空格显示"空闲"），确认是否误入 Today
**建议**：
- 无排期时不显示"预计 X 分钟"，改显示"待排期"（弱化）
- 已用时间若无数据显示"—"而非"0 分钟"
- 核查"闲/空闲"文案来源，确认不属于 Today

### P2-3 · 今日卡片尺寸偏小
**现象**：信息密度不足（预计/已用/进度挤在很小的卡片里）。
**建议**：对照 FocusCard-V2-UI副本.html 定稿稿，检查弹性布局下卡片是否未达设计稿尺寸。

## 二、收纳 Inbox 页（2 项）

### P1-4 · 新建项目/子项目输入框无法取消
**现象**：点"新建项目"或"建立子项目"后，输入框出现但**无法取消/关闭**，必须完成输入或耗在页面上。
**根因**：inbox/page.tsx 第 56 行只有 `Escape` 清空值（`setValue("")`），没有"关闭输入框"的取消逻辑；第 166 行有取消按钮但可能不在新建项目场景。
**建议**：
- Escape → 直接关闭输入框（不是清空值）
- 输入框旁加「✕」取消按钮
- 失焦（blur）关闭

### P1-5 · 任务形态无法表达（"采购元器件"问题）
**现象**：输入"采购元器件"→ 被识别为想法（inbox），确认表单无法指定"清单型/积累型/时间型"。
**根因**：形态不落库（决策 D12），由数据推导；inbox 无子任务/积累意图入口。
**建议**（需产品决策，见 §六）：
- Inbox 确认表单加「形态意图」轻量入口：加子任务 → 自动清单型；标记"每天/每周"→ accumulate=true；不加 → 保持收集箱
- 不破坏"形态由数据推导"红线，只是提供表达入口

## 三、Project 页（3 项）

### P1-6 · 待整理池项拖不动（已核实 bug）
**现象**：待整理池（右侧"待整理 · 今天要归位的"）的项**没有 draggable 属性**，拖不进左侧项目树；而树节点本身可拖（第 384 行）。
**根因**：`poolList` 渲染项缺少 `draggable` + `onDragStart`（tree 有，pool 漏了）——**与收尾批次 B1 简报声称的"待整理池项可拖入树"不符**。
**建议**：
- 给待整理池项补 `draggable` + `onDragStart`（dragSource="pool"），复用现有 drop 逻辑（dragSource === "pool" 时挂为子级）
- 这是明确 bug，**建议优先修复**

### P2-7 · 页面字号普遍偏小
**现象**：大量 `text-[12px]`/`text-[13px]`（核查到 7+ 处 13px 以下），树行/说明/徽章阅读吃力。
**建议**：整体字号体系上调一档（12→13、13→14），对照 Project-优化副本-2026-08-04.html 定稿稿核对。

### P2-8 · 树行信息密度过高
**现象**：徽章 + 主题角标 + 执行清单徽章 + 金点 + ★ + 完成度 挤在一行。
**建议**：P2-7 字号调整时一并权衡，必要时次要信息移入 hover 或详情。

## 六、需要产品决策的事项

### D-新1 · "想法"与"任务"的边界
**矛盾**：当前无时间无截止的输入 → inbox（想法），需确认后才算任务。用户感知"采购元器件应该直接是任务"。
**选项**：
- A. 保持现状（想法是"待确认"，确认后即任务）—— 只改进确认表单的表达（P1-5）
- B. 无时间任务直接建成"任务"（taskType=planned 无 deadline）—— 改变 Inbox 语义，影响面大
- **建议 A**：保持理念，补表达入口，最小改动

### D-新2 · 形态意图入口的形态
P1-5 的"清单/积累/时间"表达入口，建议做成：
- Inbox 确认表单：每项下方三个轻量动作（"加子任务" / "设为每天" / "设为有截止"）
- 档案面板：同样三个动作可后补
- 均转化为**数据操作**（建子任务/置 accumulate/写 deadline），不新增形态字段
