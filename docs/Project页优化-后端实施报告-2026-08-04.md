## 阶段 A：项目派生色（themeColor）✅

**新增** `src/lib/project/theme-color.ts`（纯函数，零 LLM）：

| 函数 | 说明 |
|------|------|
| `deriveProjectThemeColor(tasks)` | 统计任务集 theme/category 主频 → theme 主频命中取 THEMES 色 → 无 theme 按 category 主频取领域色 → 都无 null |

**树接口** `GET /api/projects/tree`：project 级节点加
```ts
themeColor: { pcolor: string; pbg: string; theme: string | null } | null
```
聚合范围为该项目下**所有子孙任务**（含子级），前端零计算。

冒烟实测：「四轴飞行器」（自身无 theme，子任务 2×竞赛）→ `#DB2777/竞赛`；「考研复习」→ `#F97316/考研` ✅

## 阶段 B：待整理池 AI 建议归属（suggestion）✅

| 规则 | 说明 |
|------|------|
| ① 标题匹配 | 孤儿标题含目标节点标题关键词（≥2 字）→ `title-match` |
