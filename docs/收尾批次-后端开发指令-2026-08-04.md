## 阶段 A · accumStats 返回当月打卡日期（唯一改动）

**背景**：前端要补积累·每日卡的「当月小日历」（V1 有 V2 漏迁），需要"当月哪些天打了卡"。

**现状**：`src/lib/task/accum.ts` 的 `getAccumStats()` **已经算好了 `monthDates`**（内部 `dates.filter(d => d.startsWith(monthPrefix))`），但返回对象里**没有暴露这个字段**——只返回了 monthCount/monthTotalDays 等聚合数。

**改动**（2 处，都是透传）：

**A1 · `src/lib/task/accum.ts`**：`getAccumStats` 返回对象加：
```ts
monthDates: string[]   // 当月打卡日期（YYYY-MM-DD，升序，已去重）
```
（变量已在函数内算出，直接加入 return 即可）

**A2 · `src/app/api/views/today/route.ts`**：currentTask 的 `accumStats` 组装处透传 `monthDates`（现有 spread 处自动带出，确认类型定义同步）。

**A3 · 单测**：`tests/` 下补 1 个用例——构造含当月/上月 checkin TimeLog 的任务，断言 `monthDates` 只含当月日期且升序去重（可参考现有 accum 相关测试的写法）。
