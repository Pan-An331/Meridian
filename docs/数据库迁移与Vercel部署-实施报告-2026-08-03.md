## 阶段 B：数据迁移 ✅（方案 B，Node 脚本）

环境无 pgloader（Windows），采用主文档 §3 **方案 B**：

| 项 | 说明 |
|----|------|
| 迁移脚本 | `scripts/migrate-sqlite-to-pg.mjs`（新增）：node:sqlite 只读 dev.db → pg 批量插入（ON CONFLICT DO NOTHING 幂等） |
| 表依赖 | `SET session_replication_role = replica` 跳过外键检查（tasks.parentId 自引用 + 表间 FK；主键全 UUID 无顺序依赖） |
| 时间戳处理 | **关键**：SQLite 把 DateTime 存成毫秒整数（1784790508669），PG TIMESTAMPTZ 需 ISO —— 脚本自动检测 >1e11 整数 → `new Date(v).toISOString()` |
| dev.db 备份 | ✅ 原文件保留 + `prisma/dev.db.bak-pre-migrate` 双备份（永久保留） |
| 本地 PG | 便携版 PostgreSQL 16.4（.pg-local/，338MB zip 分段下载 + 解压，initdb + postgres 前台运行，不入 git） |

**迁移结果：20 表 1717 行全部写入**（users 4 / tasks 45 / schedules 21 / time_logs 132 / decision_logs 1106 / user_states 112 ...）

### 待用户操作（5 分钟，沙箱无 GitHub/Vercel/Neon 凭证）

**① 建 GitHub 私有仓库**
```bash
# 浏览器 github.com → New repository → 名称 meridian（或任意）→ Private
# 回到项目目录：
git remote add origin https://github.com/<你的用户名>/meridian.git
git push -u origin master
```

**② 建 Neon 免费库（neon.tech 注册 → Project，免费 0.5GB）**
- 拿连接串：`postgresql://<user>:<pass>@ep-xxx.aws.neon.tech/neondb?sslmode=require`
- 数据导入 Neon（任选）：
```bash
# 本地 PG 已验证，用 pg_dump 导出 → psql 导入 Neon
# 或改 DATABASE_URL 重跑：node scripts/migrate-sqlite-to-pg.mjs "<neon连接串>"
```

**③ Vercel 部署（vercel.com → Add New Project → Import meridian）**
- Framework 自动识别 Next.js（build 命令无需改）
- 环境变量：
  - `DATABASE_URL` = Neon 连接串
  - `AUTH_SECRET` = 强随机串（`openssl rand -base64 32`）
  - `AUTH_TRUST_HOST` = `true`
- Deploy → `https://meridian-xxx.vercel.app`

**④ 手机验证**：挂梯子访问 → 登录 → 五页面 → PWA 添加到主屏幕（后续补）
