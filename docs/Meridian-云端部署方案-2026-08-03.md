## 2. 免费方案架构

```
手机 / 电脑浏览器
     ↓ 国内被墙 → 挂梯子访问（你的接受项）
     ↓ 可选缓解：绑自定义域名 + Cloudflare 免费 CDN
Vercel 边缘网络（全球 CDN · 自动 HTTPS · git 部署）
     ↓
Next.js 16（serverless 函数，App Router 官方适配）
     ↓
Neon Postgres（免费 0.5GB · 闲置自动休眠，唤醒 1-2 秒）
```

**选型理由**：

| 项 | 说明 |
|----|------|
| Vercel Hobby（免费） | 100GB 带宽/月、函数调用充足、自动 HTTPS、**git push 自动部署**、可绑自定义域名 |
| Neon 免费版 | 0.5GB Postgres——个人数据量绰绰有余；自动休眠对"数据持久放宽"的你没影响 |
| Supabase 备选 | 500MB 数据库 + Auth + Storage，同为免费，作为 Neon 的 Plan B |

## 3. 数据库迁移（SQLite → Postgres）【工程师执行】

1. Prisma schema：`provider = "sqlite"` → `"postgresql"`（模型定义不变，Prisma 5.22 兼容）
2. 本地/Neon 建测试库 → `prisma migrate dev` 建表
3. 数据导出导入脚本：dev.db 各表（User/Task/Schedule/TimeLog/AgentMemory 等）→ Postgres
4. `DATABASE_URL` 切到 Neon 连接串（生产用 Vercel 环境变量注入）
5. 验证：59 测试用例通过 + 旧账号数据可读

---

## 4. 部署步骤（Vercel）【工程师执行】

```
① 代码推 GitHub 仓库（确认 next.config 无 Node 专用依赖）
② Vercel 导入仓库 → 自动识别 Next.js → 一键部署
③ 配置环境变量：DATABASE_URL / NEXTAUTH_SECRET / AUTH_SECRET
④ 完成：https://xxx.vercel.app 直接可用，手机/电脑打开即登录
```
