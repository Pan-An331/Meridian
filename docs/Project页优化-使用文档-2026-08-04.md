## 1. Project 页是什么

**结构整理台**——不是执行场。你在这一页做的事只有一件：**搭骨架**（把任务归入项目、拆层级、标锚点）。执行（打卡/勾选）不在这页做，统一去 Today 和右侧习惯区。

## 2. 页面布局

```
[项目树（左，主区）]   [待整理池（右·最大）]
                      [习惯区（打卡唯一入口）]
                      [归档（折叠）]
```

## 3. 项目树怎么用

### 3.1 层级怎么看（无图标，靠结构）

| 层级 | 长相 | 是什么 |
|------|------|--------|
| **项目根** | 浅色底分组头 + 左侧彩色竖条 + 加粗 | 一个大项目（四轴飞行器、考研） |
| **阶段** | 白底 + 空心圆点 | 项目下的阶段/模块 |
| **任务** | 白底 + 灰色小点 | 可执行的子任务 |
| **积累型** | 金边圆点 + 金色打卡点 | 习惯类（背单词/健身） |

分组头的颜色 = **项目自动派生色**（项目挂的主题 > 项目下任务主领域），不是手动选的，系统自动算。

### 3.2 拖拽

- **拖到节点上** = 成为它的子级（目标出现蓝色虚线框）
- **拖到两行之间** = 调整顺序（出现金色插入线）
- 拖拽时自动重新缩进、重绘连接线

### 3.3 新建

- 右上「＋新建项目」= 新建项目根
- 行尾 hover 出现「＋」= 在当前节点下新建子项（阶段/任务），自动挂层级

### 3.4 ★ = 执行清单开关

- 点节点的 ★：点亮 = 该节点成为**可排期执行清单**（Today 可以出发、勾选子项），名称旁出现「执行清单」徽章
- 再点 = 收回，变回纯结构容器
- 规则：有子任务的阶段/任务设为 ★ 才有意义；积累型不需要 ★（打卡逻辑不同）

### 3.5 完成度

每行尾部显示 `3/6`、`2/5`、`12天` —— 一眼看出哪个项目/阶段最该推进。

## 4. 右栏怎么用

### 4.1 待整理池（今天要归位的）

Inbox 流进来的孤儿任务都在这。每项带 **AI 建议挂入目标**（如"AI 建议 → 挂入 考研"），点「挂入」一键归位；也可以直接拖到左侧树。

### 4.2 习惯区（打卡唯一入口）

所有积累型任务的打卡**统一在这里**（树里不再有打卡按钮）。点「今日打卡」→ 完成；点阵显示本周进度；连续天数实时更新。

### 4.3 归档

已完成项目/任务折叠在此，点开查看。

## 5. 档案面板（点树节点弹出）

点任意节点 → 右侧滑出档案：归属链（项目 › 阶段 › 任务）+ 元信息 + 执行清单（memo 黄，可勾选）+ **执行类型开关**（★ 的开关就在这里）+ AI 执行建议。

## 6. 常见操作速查

| 想做什么 | 怎么做 |
|---------|--------|
| 把任务放进项目 | 待整理池「挂入」或拖到树 |
| 拆一个阶段 | 行尾 ＋ 新建子项 |
| 让阶段变成 Today 可执行 | 点 ★ |
| 调整顺序 | 拖到两行之间 |
| 打卡背单词 | 右侧习惯区（唯一入口） |
| 改执行清单内容 | 点节点 → 档案面板 |
