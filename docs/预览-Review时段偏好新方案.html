旧版问题
① 只分「上午/下午/晚上」三个大桶，粒度太粗
② 每条都是「XX 更喜欢在下午完成——任务 15:00、任务 14:00」纯文字
③ 所有分类全列出来，无重点；打断提醒混在末尾
新版思路
① 时段热度矩阵一眼看分布（清晨/上午/下午/晚上）
② 峰值格自动高亮 → 结论精确到小时窗口（如「下午 14-17 点」）
③ 只保留 2-3 条最有信息量的结论 + 任务证据标签，不再全列

📐 本方案要点：
① 热度矩阵：分类 × 四时段（清晨/上午/下午/晚上），色块长度 = 专注次数，峰值格蓝框高亮 —— 解决"全是文字没重点"
② 结论精确到小时窗口（下午 14-17 点 / 晚上 19-21 点 / 上午 9-11 点）—— 解决"上午/下午太粗"
③ 结论行 = 设计稿 ai-tag 胶囊 + 自然语言 + 任务证据标签（任务名+时间），最多 3 条 + 1 条打断注意 —— 不再全分类堆砌
④ 数据全部来自现有 /api/views/stats 的 completedTasks.timeLogs，无需新 API
