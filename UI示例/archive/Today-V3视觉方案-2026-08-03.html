方案 A · 设计要点
1880px 居中 + 深阴影：主卡是页面上唯一带重投影的元素，视觉重量压倒路线/AI 两块辅助卡（它们无边框、只有轻投影），「主角 vs 陪衬」的关系靠阴影层级直接拉开。（对应需求②⑥）
216px 大圆角 + 品牌强调：卡片四角 16px，动机行紫底横贯顶部，是整屏第一视觉锚点；字号按需求提升（标题 20px bold / 所属项目 14px semibold / 动机 12.5px / 元信息 10px 小字角标）。（对应需求④）
3一屏三块全见：简单任务下问候语 + 主卡 + 路线/AI + 状态条折叠，整屏无滚动；复杂任务时主卡清单自然延长，路线/AI 跟随下移。（对应需求③）
4AI 输入框上移：从面板底部提到紫色标题栏正下方，「先输入后看建议」的动线更顺。（对应需求⑤）

方案 B · 设计要点
1960px 左对齐：不居中、锚定左侧，像 Notion / Linear 一类效率工具——内容从左上角起读，滚动时眼睛的起点始终固定；右侧留白是「呼吸区」而非对称装饰。（对应需求②「具体值 UI 设计师按视觉定」：960 是上限）
2轻边框 + 低圆角（10-12px）+ 扁平阴影：整页只用 1px 边框和极轻投影，「工具感」强；主卡与辅助卡共享同一套边框语言，靠面积（主卡更大）+ 左栏灰底形成主角/配角关系，而不是靠阴影等级。（对应需求⑥）
3元信息最克制：地点从主卡删掉（需求④说元信息保持小字角标），放进路线段；主卡右栏更聚焦「标题 + 清单 + 动作」。（对应需求④）
4AI 输入框上移 + 建议区更紧凑（11px 行距、7px 圆角），整体密度高、信息效率优先。（对应需求⑤）

方案 C · 设计要点
1920px 居中 + 品牌氛围：问候语用品牌紫蓝渐变大字并居中，整页从「被工具包围」变成「被目标包围」——第一眼是今天的意义感，第二眼才是任务。（对应需求②⑥）
2渐变 + 柔光阴影：主卡带品牌色微光投影（box-shadow 紫 9% 透明度）、卡片描边用淡紫 #e8e5fb、进度条渐变填充、左栏浅紫渐变底——所有"强调"都染上品牌色，氛围统一。
3主卡与辅助卡同一套圆角（14-16px）：靠光晕强度和内容密度区分主次，视觉更统一、更柔和，适合晚间使用场景（Today 常晚间打开）。
4AI 输入框上移 + 输入框圆角加大（10px），与整体柔和气质匹配；状态折叠条同样带淡紫描边收尾。（对应需求⑤）

三版速览 · 怎么选

维度方案 A · 主角卡方案 B · 工作台方案 C · 沉浸
宽度 / 对齐880px 居中960px 左对齐920px 居中
气质关键词存在感、重量、视觉聚焦效率、克制、信息密度氛围、柔和、目标感
主角如何凸显重阴影 + 大圆角（唯一重影元素）面积大 + 左栏灰底（同边框语言）品牌渐变 + 柔光晕
适合场景白天办公、需要"把注意力钉在任务上"高频操作、习惯键盘工作流晚间复盘、想要情绪价值
实现成本低（只调宽度 + 阴影/圆角）低（同上）中（渐变类要核对暗色主题）
