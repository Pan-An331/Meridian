# Task OS · 导航设计方案（实施版）

> 版本：V1.0 · 2026-08-01 · 状态：已定稿（含动画与真实 UI 规格）
> 演示：`UI示例/导航栏方案演示.html`（右下角切页面 / 版式，设置页切导航）

---

## 一、设计目标

1. **工作流可视化**：导航按产品核心链路排列 —— Inbox（理解）→ Plan（规划）→ Today（执行）→ Review（复盘），带序号强化"一条链"的心智
2. **Today 是默认落地页**：登录后先进 Today（执行驾驶舱），导航中 Today 项带"默认"徽章
3. **设置降级**：设置不再与主页面平级 —— 桌面端收进侧栏底部齿轮 / 顶栏右上角，移动端收进页头齿轮
4. **导航与版式可配置**：设置页提供"导航方案"（工作流侧栏 / 顶栏）与"Focus Card 版式"（一栏 / 两栏）两个开关，改动即时生效、持久保存

## 二、导航结构（桌面端）

### 方案 A · 工作流侧栏（默认）
```
┌──────────────┬──────────────────────────────┐
│  Task OS      │  内容区（按页面类型居中）       │
│  ① Inbox 理解 │                              │
│  ② Plan 规划  │                              │
│  ③ Today 执行·驾驶舱 [默认]                  │
│  ④ Review 复盘 │                             │
│  ───────────  │                              │
│  ⚙ 设置(底部) │                              │
│  [阿哲 ⏻]     │                              │
└──────────────┴──────────────────────────────┘
```
- 侧栏 240px，深色底 `#1b1833`；激活项品牌色实底白字 `#6366f1`
- 可折叠为 64px 图标条（保留折叠交互）
- 设置 = 底部齿轮图标；用户区在底（头像 + 名称 + 退出）

### 方案 B · 顶栏
```
┌──────────────────────────────────────────────┐
│ Task OS │  Inbox  Plan  Today  Review  │ ⚙ 阿哲 │
├──────────────────────────────────────────────┤
│ 内容区（全宽 or 居中，规则同 A）                │
└──────────────────────────────────────────────┘
```
- 顶栏 56px 深色，Brand 左、四页面 Tab 居中、设置齿轮 + 头像右上
- 激活 Tab 品牌色胶囊背景

### 共同行为
- 导航项点击切页并**联动高亮**（侧栏按钮 / 顶栏 Tab）
- 快捷键 `Ctrl + ↑ / ↓` 在页面间循环切换（已有实现，顺序同步为工作流序）

## 三、宽度规则（页面级，居中）

| 页面 | 宽度 | 理由 |
|------|------|------|
| Today | 1100px 居中 | 执行驾驶舱，操作型内容需要舒展（读 vs 干 → 干） |
| Plan | 1100px 居中 | 周历 7 列 + 时段轴，横向需求最大 |
| Inbox / Review / 设置 | 720px 居中 | 阅读/输入/配置型，45-75 字符行宽最佳 |

实现：内容容器 `.pg-wrap { max-width: 720px }` / `.pg-wide { max-width: 1100px }`，`margin: 0 auto` 居中。

## 四、Focus Card 版式（可配置）

设置页提供 **方案一（一栏）/ 方案二（两栏）** 切换，仅影响 Focus Card 本身；下方"今日路线 + AI 助手"两版均保持双栏。

### 方案一 · 一栏（放大版，1100 内纵向铺开）
```
画原理图（24px 标题）
[清单型] 预计 90 分钟
执行清单：3 项（勾选态）
已完成 1/3 · 总耗时 22 分钟
33% 进度条
[跳过] [完成 1 项]
AI 执行：上次类似任务你花了 90 分钟
做产品/项目 — 以产出清单为准，计时是辅助
```

### 方案二 · 两栏（左信息栏 36% + 右内容区 64%）
```
左：项目名 / 阶段进度 3-6 / 阶段列表(当前高亮) / 类型 / 时间 / 本任务 33%
右：标题 / 执行清单(状态徽标: 18分·进行中·待开始) / +追加·标记完成 / AI / [跳过][完成]
```

### 三种任务类型共用骨架
| 类型 | 左/上主体 | 右/下操作 |
|------|----------|----------|
| 计时型 | 圆环计时器 + 领先/消耗/剩余 | 暂停 / 完成 |
| 清单型 | 执行清单（黄色 memo） | 跳过 / 完成 1 项 |
| 学习型 | 知识点勾选（可逆） | 暂停 / 完成 |

## 五、动画规格

| 场景 | 动画 | 参数 |
|------|------|------|
| 页面切换 | 内容区淡入 + 上移 | `opacity 0→1`，`translateY(6px)→0`，0.28s ease |
| 导航方案切换 | 面板淡入 | 0.22s ease |
| 激活项高亮 | 背景/文字色过渡 | 0.15s ease |
| 侧栏折叠 | 宽度过渡（已有） | 0.2s ease |
| 移动端 Tab | 胶囊背景过渡（已有） | 0.2s ease-out |
| 减少动态 | 遵循 `prefers-reduced-motion`，全部降级为直接切换 | — |

## 六、设置联动（导航与版式）

设置页新增「🧭 导航与版式」卡片：
```
导航方案         [工作流侧栏 | 顶栏]
Focus Card 版式  [一栏 | 两栏]
```
- 选择**即时生效**（全局状态变更 + 重渲染）
- 持久化：`localStorage`（key: `taskos.nav` = `'side'|'top'`；`taskos.fcLayout` = `'1'|'2'`），刷新保留
- 演示稿中右下角"版式"按钮保留，与设置项双向同步

---

## 七、响应式（移动端）

- 桌面（≥1024px）：侧栏 / 顶栏（按设置）
- 移动（<1024px）：**底部浮动胶囊导航**（iOS 26 风格，毛玻璃），4 个主 Tab（Today / Inbox / Plan / Review），设置入口 = 页头右上齿轮
- Focus Card：<700px 时两栏自动降级一栏（`.fc-2col { grid-template-columns: 1fr }`，分隔线改上边框）
- Today 辅助区（路线 / AI）窄屏堆叠为单列

- Settings 页新增「导航与版式」卡片（seg 控件）
- 存储：`localStorage`（首版）→ 后续可迁移 UserProfile 字段

### 动画
- 全局 CSS keyframes `fadeInPg`（0.28s）
- 页面切换时对内容容器重触发动画
- `@media (prefers-reduced-motion: reduce)` 关闭过渡

## 九、验收标准

1. 两种导航形态可随时切换，激活高亮、快捷键、移动端 4 tab 均正常
2. Focus Card 一栏/两栏切换后，下方辅助区不变（始终双栏）
3. 宽度：Today/Plan 1100 居中、其余 720 居中
4. 刷新后设置保留
5. `npm run build` 通过
