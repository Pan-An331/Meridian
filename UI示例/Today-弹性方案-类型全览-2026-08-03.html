简单 / 复杂怎么判定？—— 建议规则

1不看清单条数，看"主卡实际高度"：渲染后测量 主卡 + 问候语 的总高度。≤ 一屏可用高度（约 560-600px）→ 简单态；超出 → 复杂态。这样 0 条清单的时间型、3 动作的健身、10 项的原理图各自自动归位，不用写死阈值。
2简单态：宽度 760px 居中，三块一屏（主卡 + 路线|AI + 状态条全见）。
3复杂态：宽度 880px 居中，首屏只放问候语 + 主卡；路线|AI 完整沉底、状态条继续折叠。
4切换动画建议 200ms 宽度过渡（同款 CSS transition），简单↔复杂顺滑无跳变。
